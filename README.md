# Huellas que vencieron el fuego — Sustentación interactiva

Aplicación HTML de una sola página para la **presentación dinámica del trabajo de grado** de Daisy Johana Fernández Girón: *Recuperación de información sobre la trayectoria e incidencia pública de Arcenio Fernández Vega: aportes a la memoria histórica de Támara y Trinidad, Casanare (Colombia)*. Pontificia Universidad Javeriana · CIBAR · 2026.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| **`presentacion.html`** | La presentación en modo diapositivas (37 diapositivas, navegación con flechas). Es el archivo que se abre para la sustentación. |
| `index.html` | Recorrido narrativo de lectura continua por capítulos del mismo trabajo. |
| `assets/img/` | Figuras y anexos del documento de grado usados en la presentación. |

## Cómo exponer

1. Abre `presentacion.html` en un navegador moderno (Chrome, Edge, Firefox o Safari).
2. Pulsa **F** para pantalla completa y **V** para abrir la vista de presentador en una segunda ventana (reloj, notas y diapositiva siguiente) — ideal si usas dos pantallas.
3. Avanza con **→** y retrocede con **←**.
4. Si prefieres un PDF: pulsa **P** y elige «Guardar como PDF» (sale una página de 1280 × 720 por diapositiva).

### Atajos

| Tecla | Acción |
|---|---|
| `→` `↓` `Espacio` `Av Pág` | Diapositiva siguiente |
| `←` `↑` `Re Pág` | Diapositiva anterior |
| `Inicio` / `Fin` | Primera / última diapositiva |
| `O` | Índice de las 37 diapositivas |
| `N` | Guion del expositor (notas, cuidados y tiempos) |
| `V` | Vista de presentador (segunda ventana) |
| `T` | Cronómetro de la exposición |
| `F` | Pantalla completa |
| `B` | Pantalla en negro (para pausas o preguntas) |
| `P` | Imprimir / guardar en PDF |
| `Esc` | Cerrar ventanas emergentes |
| `?` | Ayuda con todos los atajos |

También funciona con clic en las flechas laterales y con gestos de deslizamiento en tablet y móvil.

## Estructura de la presentación (37 diapositivas, ≈ 22 minutos)

1. **Apertura** — portada, ruta de la sustentación y divisores de bloque.
2. **Problema y propósito** — un hombre público sin expediente, pregunta orientadora, objetivos y justificación.
3. **Método y corpus** — diseño metodológico, tres fases de campo, los 17 registros del corpus y las tres partidas que anclan la cronología.
4. **Trayectoria** — trece estaciones entre 1889 y 1974, el código ético, los dos hogares, Trinidad en 1953, el archivo familiar y la etapa final.
5. **La prueba** — coindicencias, divergencias, vacíos, rutas frustradas y geografía de la búsqueda.
6. **Aportes** — conclusiones en dos partes, aportes y horizontes, recomendaciones, referencias y cierre para preguntas del jurado.

## Criterios de fidelidad

- Todo el contenido proviene del documento de grado y sus anexos: no se añadieron datos, fechas, citas ni testimonios externos.
- Cada afirmación indica su nivel de evidencia: **documentado**, **corroborado**, **memoria oral** o **hipótesis / vacío**.
- Los pies de imagen conservan la nota de fuente del documento, incluida la indicación de **restauración con Meta AI** en las fotografías familiares.
- Los consentimientos informados no se reproducen, para proteger a las personas participantes.
